# Chairunnisa Yasfa — Personal Portfolio

A personal showcase portfolio website by **Chairunnisa Yasfa**, an Informatics Engineering student at Politeknik Negeri Batam. Designed with a soft pastel sky aesthetic, subtle glassmorphism UI, and interactive animations to present work across **Mobile Development**, **Web Development**, and **UI/UX Design**.

> **Live Demo:** _Coming Soon_

## ✨ What's Inside

- **Pastel & Glassmorphism Aesthetic** across the Landing, Contact, and Resume pages.
- **Interactive Hero Section** featuring animated rotating roles and custom ASCII art.
- **Project Showcase** with detail pages and interactive galleries.
- **Dedicated Resume Page** with a structured CV summary and downloadable PDF.
- **Responsive Design & Smooth Animations** tailored for both desktop and mobile viewports.

## 🛠️ Built With

- **Core:** React 19, TypeScript, Vite, React Router DOM
- **Styling & UI:** Tailwind CSS, Radix UI, Lucide Icons
- **Motion & Graphics:** GSAP, React Spring, OGL (WebGL)
